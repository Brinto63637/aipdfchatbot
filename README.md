# AI PDF Chatbot (Ollama)

A small local web app for asking questions about PDF documents. PDF text is indexed in memory, and answers are generated by an Ollama model running on your computer. Uploaded files are not saved to disk.

## Requirements

- Python 3.10+
- [Ollama](https://ollama.com/) installed and running

## Start it

```powershell
cd $HOME\Documents\aipdfchatbot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull smollm2:1.7b
python -m uvicorn app:app --reload
```

Open http://127.0.0.1:8000. Keep Ollama running while chatting.

By default the app uses `smollm2:1.7b` at `http://localhost:11434`. To use another installed model, set `OLLAMA_MODEL` before starting the server, for example `$env:OLLAMA_MODEL = 'qwen2.5:7b'`.

## Notes

- Upload supports text-based PDFs up to 30 MB. Scanned PDFs need OCR before upload.
- Uploaded document text stays in server memory and is cleared when the app stops.
- Retrieval uses simple term matching to select relevant page passages; citations show the PDF filename and page.
- This is a local starter app. Do not expose its server to an untrusted network without adding authentication and request limits.
